# Deeplabv3plus 项目环境/迁移/协作说明

## 1. 环境管理

- 推荐使用 Docker 或 Conda 管理环境。
- Docker：支持多GPU/多CUDA，见 Dockerfile，构建时根据硬件选择参数。
- Conda：见 environment.yml，PyTorch等需按硬件单独安装。

## 2. 代码管理

- 推荐用 Git 进行版本管理。
- .gitignore 已配置，忽略大文件、权重、图片、临时文件等。

## 3. 运行结果管理
- 权重、可视化图片、日志等建议用网盘归档。
- 可用 auto/ 目录下自动化脚本批量整理、归档、重命名。

## 4. 多设备迁移/协作流程
1. 代码用 Git 同步，环境用 Docker/Conda 还原。
2. 训练/推理结果用自动化脚本整理后上传网盘。
3. 新设备拉取代码、还原环境、同步结果即可复现。

## 5. PyTorch/深度学习依赖适配建议
- 服务器（24G显存，CUDA 12.1）：
  conda install pytorch=2.2.0 torchvision=0.17.0 pytorch-cuda=12.1 -c pytorch -c nvidia
- 个人电脑（8G显存，CUDA 11.8）：
  conda install pytorch=2.1.0 torchvision=0.16.0 pytorch-cuda=11.8 -c pytorch -c nvidia
- 也可用 pip 安装特定版本，见 Dockerfile 注释。

## 6. 其它建议
- 结果归档建议定期整理，避免网盘混乱。
- 代码、环境、结果三分管理，迁移和协作最省心。
