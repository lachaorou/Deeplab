# Deeplab 项目训练脚本与自动归档优化学习笔记

## 1. 参数交互与美观输出（总览）

- 支持所有关键参数（含 tokens 机制）交互修改，参数名+中文解释。
- 参数以表格形式美观输出，提升用户体验。

## 2. 权重加载逻辑

- 默认加载预训练权重，用户可输入绝对路径自定义。
- 路径校验，避免相对路径混乱。

## 3. 训练结果自动归档

- 日志、权重、miou、可视化图片全部按模型名+时间归档到 Results 下对应子目录（logs_xxx、mious_xxx、visual_xxx）。
- 结构示例：

  ```text
  Results/
    logs_deeplab/20250612_1530/
    mious_deeplab/20250612_1530/
    visual_deeplab/20250612_1530/
  ```

## 4. 评估与消融实验自动化

- 训练结束后自动调用 get_miou.py 评估脚本，解析 mIoU、mPA 等指标。
- 评估结果与本次训练参数自动写入 csv 表格，实现消融/对照实验自动化。
- 评估结果 csv 自动归档到 Results/mious_xxx/时间/exp_results.csv。

## 5. 可视化报告自动生成

- 训练结束后自动生成 Word 和 PDF 可视化报告，图片按样本为主嵌入表格，报告自动归档到 Results/visual_xxx/时间/。
- 便于查阅和对比，无需手动整理图片和报告。

## 6. 其它优化要点

- 删除以 epoch 为主的可视化相关代码，只保留 by_sample 可视化。
- 训练脚本结构优化，参数传递、路径拼接、日志输出等细节完善。
- 冗余注释精简，代码更易维护。

## 细节补充

### 1. 参数交互与美观输出（细节）

- 参数交互通过 input() 支持批量输入，格式如 `batch_size=8; token_length=120; input_shape=[1536,1024]`。
- 参数表格输出采用英文+中文解释，便于理解。
- tokens 机制相关参数（如 token_length、num_layers、embed_dims、patch_size、use_softmax、scale_init）均可交互修改。

### 2. 权重加载流程

- 默认加载主干预训练权重（mobilenet_v2.pth.tar 或 xception_pytorch_imagenet.pth），路径自动拼接。
- 用户可输入绝对路径自定义权重，路径校验避免误用相对路径。
- 权重加载交互逻辑清晰，避免误操作。

### 3. 训练结果归档目录命名规范

- 归档目录命名采用 `Results/类型_模型名/时间/`，如 `Results/logs_deeplab/20250612_1530/`。

- 日志、权重、miou、可视化图片等全部归档到对应目录，便于溯源和管理。
- 每次训练自动新建时间戳子文件夹，避免结果混杂。

### 4. 评估与消融实验自动化（细节）

- 训练结束后自动调用 `get_miou.py`，支持命令行参数 `--log_dir --output_dir`。
- 评估脚本输出的 mIoU、mPA 等指标自动解析，写入 csv。
- csv 字段建议：参数（如主干、batch_size、input_shape、tokens相关）、指标（mIoU、mPA）、训练时间、权重路径等。
- 支持多次实验结果自动追加，便于对照分析。

### 5. 可视化报告自动生成（细节）

- 训练结束后自动调用 `export_visualization_to_word.py` 和 `export_visualization_to_pdf.py`，生成 Word/PDF 报告。
- 脚本支持 `--input_dir --output` 参数，图片按样本为主嵌入表格。
- 报告自动归档到 `Results/visual_xxx/时间/`，便于查阅。
- 建议表格结构：第一行原图，第二行标签，第三行及以后为各权重/epoch的预测图片。

### 6. 其它建议

- 训练脚本、可视化脚本、评估脚本均支持自动归档和表格化输出，极大提升实验复现和论文撰写效率。
- 目录结构、文件命名、参数与指标表格化均已标准化，便于团队协作和长期维护。
