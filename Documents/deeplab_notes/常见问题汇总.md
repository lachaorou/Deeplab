# 常见问题汇总

## 1. 代码与数据集下载
- 代码一般在项目的 README 或课程资料中有下载链接，注意下载最新版本。
- 下载压缩包损坏时建议重新下载，或换用其他网络环境。
- 数据集下载地址通常在 README 或课程说明中，部分数据集需自行申请或从公开平台获取。

## 2. 权重文件问题
- 有些项目不会直接附带权重文件，需要根据说明单独下载。
- 权重文件下载后要放到指定的 model_data 或权重目录下，否则训练/推理会报错。

## 3. 环境配置
- 建议严格按照项目 requirements.txt 或说明文档配置 Python 版本和依赖库。
- 显卡驱动、CUDA、cuDNN 版本要与 PyTorch/TensorFlow 等深度学习框架兼容。
- 30 系显卡建议用 PyTorch 1.7+、CUDA 11+，老显卡可用 1.2/1.4/1.6 等版本。

## 4. GPU 利用与加速
- 安装好 CUDA 后，训练时可用 nvidia-smi 查看显存占用，确认是否用上了 GPU。
- 若训练速度慢、显存未被占用，需检查环境变量、驱动和 CUDA 配置。

## 5. 训练与评估常见报错
- OOM（显存溢出）：调小 batch_size 或 input_shape，或减少 num_workers。
- 权重/日志/miou 路径错乱：建议统一规范目录结构，避免不同主干/实验混用同一目录。
- 标签文件缺失/损坏：用 check_label_values.py、check_label_validity.py 等脚本批量检查。
- 训练/验证集类别分布极不均衡：建议用 auto_split_train_val.py 自动划分，保证评估科学性。

## 6. 其它经验
- 训练前建议用脚本检查数据集完整性，避免训练中断。
- 训练日志、权重、评估结果建议分主干/实验单独保存，便于后续对比和复现。
- 如遇新问题，优先查阅项目文档和历史记录，再针对性排查。
