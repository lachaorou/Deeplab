## 8. 自动化训练、评估与特征可视化批量保存（实验2、实验3等可参考）

### 8.1 自动化训练脚本说明
- 自动化训练指通过脚本（如 train.py）实现一键启动训练，自动加载数据、设置参数、保存模型、记录日志等，无需手动逐步操作。
- 可通过命令行参数（argparse）或配置文件（如 config.yaml）灵活指定 batch_size、学习率、backbone、消融参数（use_tokens）等。
- 支持多组参数批量实验（如循环不同 batch_size、backbone、消融组合），自动保存每组实验的模型与日志。
- 建议每次实验自动生成唯一实验名（如含实验编号、参数摘要），便于结果归档。

### 8.2 评估脚本自动化
- 评估脚本（如 get_miou.py）可批量读取指定目录下的模型权重，对验证集/测试集自动评估，输出 mIoU、PA、混淆矩阵等。
- 支持自动保存评估结果（如 csv/txt），便于后续对比与分析。
- 可扩展为自动对比不同实验结果，生成汇总表格。

### 8.3 特征可视化批量保存实现建议
- 在推理/验证循环中，遍历待分析图片，依次调用 detect_image（或 forward），再调用 save_tokens_feature，按图片名批量保存特征图。
- 可写成专用脚本（如 feature_vis_batch.py），或在 predict.py、get_miou.py 等中增加批量特征保存逻辑。
- 建议保存为统一文件夹，命名规范如 feature_vis/xxx_channel_0.png，便于后续分析。
- 可扩展为自动统计特征分布、可视化对比不同模型/参数下的特征差异。

### 8.4 实验结果自动汇总
- 建议每次训练/评估/可视化均自动保存结果（如 loss、miou、特征图路径等），并汇总为总表（如 results.csv）。
- 可用 pandas 等工具自动生成对比分析报告。

### 8.5 经验与建议
- 强烈建议每次实验都补充本记录文件，详细记录参数、结构、消融、可视化、结果、经验等。

# 深度学习项目 Cityscapes/VOC 语义分割 学习记录

## 1. 环境与工具配置
- VSCode 需安装 Microsoft 官方 Python 扩展，左下角选择具体解释器路径（如虚拟环境、Anaconda）。
- 若遇到 python.setInterpreter not found，需重装 Python 扩展或升级 VSCode。
- `.vscode/launch.json` 配置如下，便于一键运行/调试当前 Python 文件：
  ```json
  {
      "version": "0.2.0",
      "configurations": [
          {
              "name": "Python: 当前文件",
              "type": "python",
              "request": "launch",
              "program": "${file}",
              "console": "integratedTerminal",
              "justMyCode": true
          }
      ]
  }
  ```
- 保证 PyCharm 与 VSCode 使用同一虚拟环境或解释器，依赖包一致，路径设置一致。

## 2. 数据集处理与检查
- 用 `auto_copy_cityscapes_to_voc.py` 自动补全 VOC 缺失的标签和图片，支持图片格式转换。
- 用 `check_missing_labels.py` 检查 VOC 标签和图片缺失情况。
- `gen_voc_train_txt.py`、`gen_voc_val_txt.py` 生成 VOC 格式的 train/val 划分。
- `halve_voc_split_and_clean.py` 可将 train.txt/val.txt 数量减半，并同步清理未用图片和标签。
- `check_label_values.py` 随机抽查标签文件，自动判断 trainId/labelId 类型，检查像素值是否合法，辅助定位标签映射问题。

## 3. 训练与调试
- `FileNotFoundError`：检查 label 路径拼接，确保加上 `_gtFine_labelTrainIds.png`。
- `IndentationError`：注释 print 时注意空代码块需加 `pass`。
- 训练脚本中多余 debug 输出可注释或删除，保持日志简洁。
- 训练过程中不要重启 VSCode/电脑，否则进程会被中断。
- 如需调试其他脚本，建议新开终端或等训练完成后操作。

## 4. 结果分析与后续优化
- mIoU 过低排查思路：检查标签像素值、类别映射、数据集划分、模型结构与损失函数设置。
- 用 `check_label_values.py`、`stat_label_distribution.py` 等脚本辅助分析。
- 保持数据、代码、环境一致性，逐步排查数据、模型、训练流程，记录每次实验参数与结果。
