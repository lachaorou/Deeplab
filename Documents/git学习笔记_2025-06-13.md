# Git 学习笔记（2025-06-13）

## 1. 基本概念

- **本地仓库**：你电脑上的项目版本库。
- **远程仓库**：GitHub 上的项目仓库。
- **分支**：main（主分支，推荐使用）、master（历史遗留分支）。
- **提交（commit）**：保存一次本地更改。
- **推送（push）**：把本地提交上传到 GitHub。

## 2. 常用命令

- 初始化仓库（已完成）：`git init`
- 关联远程仓库：

  ```sh
  git remote add origin https://github.com/用户名/仓库名.git
  ```

- 检查分支：`git branch -a`
- 切换分支名为 main：

  ```sh
  git branch -m master main
  ```

- 拉取远程 main 并合并：

  ```sh
  git pull origin main --allow-unrelated-histories
  ```

- 推送到远程 main：

  ```sh
  git push -u origin main
  ```

- 删除远程 master 分支：

  ```sh
  git push origin --delete master
  ```

## 3. 日常操作流程

1. 编辑文件
2. 保存（Ctrl+S）
3. `git add .`
4. `git commit -m "说明"`
5. `git push`

## 4. 注意事项

- main 作为主分支更规范，和 GitHub 默认一致。
- 删除 master 分支前，确保 main 分支内容完整。
- 每次推送前建议先 `git pull` 保持同步。

## 5. 其它

- `.gitignore` 文件用于忽略不需要上传的文件。
- GitHub 网页端可管理分支、设置默认分支、删除分支。
